# Linear regression with NumPy

Install the local dependencies with `python -m pip install -r requirements.txt`. Run `python setup.py` to copy the starter into `work/`. Implement the TODOs in `work/linreg.py`, then run `python verify.py`. The verifier reads the acceptance thresholds from the project YAML and writes `work/results.json`; upload that JSON on the Academy lab page. The app validates results as data and never runs learner code.

The reference implementation used by the project tests is in `_solution/`.
